## Лекции 1-2 

1. **Celsius and Fahrenheit Converter**: перевод по формулам `F = C * 9 / 5 + 32` и `C = (F - 32) * 5 / 9`.
2. **Road tax**: цепочка `if / elif / else` по стоимости байка, ставка 15 %, 10 % или 5 %.
3. **Data Format (Yandex Contest)**: дата однозначна, если `x == y` (оба прочтения совпадают)
   или одно из чисел больше 12 (месяцем может быть только другое).

## Лекции 3–4 

1. **First 10 natural numbers**: цикл `while` со счётчиком.
2. **Max element**: проход по списку `for` с запоминанием текущего максимума.
3. **Factorial**: накопление произведения в цикле `for` по `range(1, n + 1)`.
4. **Fibonacci series**: список `[0, 1]`, каждый следующий элемент — сумма двух предыдущих (`append`).
5. **Pattern**: строка `"* " * i` в двух циклах `for`, по возрастанию до `n` и по убыванию через `range(n - 1, 0, -1)`.
6. **Numbers except ranges**: `for` по `range(1, n + 1)` и `continue` для чисел из запрещённых диапазонов.
7. **Robot Return to Origin**: координаты `x, y` меняются по каждому символу (`if / elif`), в конце проверяется `x == 0 and y == 0`.
